# 命令

命令补全优先展示常用操作，可按名称、别名与描述关键词查找。指向当前进程内已有对象的参数同样会补全——`/model dee` 列出各 provider 中匹配的模型，`/resume` 列出已有会话，`/login` 列出已注册的 provider——按 Enter 直接执行已写的那一行。`/help` 按任务分组；第三方插件命令仍可发现。

在 composer 中输入 `/` 即可浏览实时命令目录并查看参数提示；输入 `/help` 会把命令列表与常用快捷键打印进对话（`/help full` 会补全完整键盘目录）；超过十二行的结果折叠成一行，`Ctrl+O` 展开。命令目录由当前挂载的插件组成，因此 Skills 与用户插件包贡献的命令会和内置命令一起出现。`/help` 按用户任务分组展示目录，包括扩展命令。在文档阅读器内（文件恢复、插件设置、会话组合）按 `/` 打开查找行，搜索的是渲染后的行：计数随输入更新，Enter 跳到第一处，Ctrl+N/Ctrl+P 在命中之间移动。命令结果——包括 `/help` 与 `/changelog`——留在对话里，过长时折叠。

`[方括号]` 表示可选参数，`|` 表示多选一。带选择器的命令不需要参数。

## 会话

| 命令 | 作用 |
|---|---|
| `/new` | 新建会话。 |
| `/resume [session-id\|query]` | 不带参数时打开会话库；带查询时搜索持久会话内容并恢复选中的结果；带 id 时直接恢复。在会话库中按 `p` 置顶、按 `r` 重命名。 |
| `/session` | 显示当前会话的详细信息。 |
| `/continue` | 继续可恢复的模型失败，不重复发送提示。 |
| `/retry` | 将最近一条用户提示连同图片和文件作为新回合重发。 |
| `/clear` | 清空可见转录，并留下一条接缝。正在运行的回合、状态、todos 和排队消息保持原状。 |

## 会话配置

| 命令 | 作用 |
|---|---|
| `/agent` | 选择 Agent preset：Standard、PTC、Minimal 或 Creator。仅在空白会话可用；不可用的 preset 会显示失败原因。`/agent inspect [preset-id]` 查看声明及当前会话保留的 composition。`code`（PTC）preset 把注册表呈现为生成 SDK，并隐藏 `workflow_run`。 |
| `/agent creator` | 进入 Creator（`cordis`）创作插件。复用空白会话，已有对话时新建会话；保留各会话草稿，不改变默认 preset，也不提交提示。 |
| `/permission` | 选择会话 Access 级别，或查看、撤销记住的审批规则。 |
| `/login` | 登录 provider：目录条目、API key、DeepSeek 账户浏览器登录（或已共享的授权），或自定义 provider（自带 id、base URL、协议与模型 id）。 |
| `/logout` | 删除存储在文件中的提供方凭据，或登出共享的 DeepSeek 账户；环境变量提供的值保持不变。 |
| `/settings` | 打开 General、Models、Agent presets、Plugins、Terminal 与 Advanced 设置。别名：`/set`。 |

### `/model`

| 形式 | 效果 |
|---|---|
| `/model` | 打开一个可搜索的列表，列出所有 provider 的全部模型，并标出当前模型。`Enter` 切换保存的默认值；`Ctrl+D` 只对当前会话生效。采用目标模型的默认推理强度，不再追加询问；用 `/model reasoning` 修改强度。 |
| `/model <query>` | 解析 `provider/model` 或模糊模型名；精确匹配立即切换，歧义时打开过滤后的列表。 |
| `/model --session` | 同一个列表，只作用于当前会话，不写入保存的默认值；也可附带查询。不能与子命令组合。 |
| `/model next` / `/model previous` | 切换到下一个或上一个收藏模型。 |
| `/model reasoning` | 循环切换当前模型的推理强度。 |
| `/model favorite` / `/model unfavorite` | 把当前模型加入或移出本地收藏列表，保存在 `$OMDSH_HOME/omdsh/model-favorites.json`。 |
| `/model favorites` | 列出收藏的模型。 |

## 回合控制

| 命令 | 作用 |
|---|---|
| `/queue` | 逐条查看、编辑、删除和调整待处理用户消息的顺序。 |
| `/btw <question>` | 基于当前已提交的会话快照另问一个问题，回答显示在 composer 上方的面板里。 |
| `/questions` | 回答限时等待后留下的问题，也可用于恢复的会话。 |
| `/plan [off\|<message>]` | 进入 Plan 模式并可同时发送首个规划请求，`off` 直接退出。composer 中的图片和文件会随规划请求一起发送。 |
| `/goal [<objective>\|clear\|edit <objective>\|pause\|resume]` | 为会话设置或查看长期目标。 |
| `/compact` | 压缩较早的对话历史；压缩期间可继续输入并排队，完成后用 Ctrl+O 阅读已保存的摘要。 |
| `/jobs [<id>\|kill <id>]` | 浏览实时后台任务、查看保留的输出，或确认停止任务。行模式打印快照与运行叙述。 |

## 目标管理

`/goal` 保留 Harness 原有命令语法。按 `Alt+G`，或打开 **Settings → General → Current goal**，可编辑、暂停、继续或清除当前目标，不会提交输入框草稿。清除需要确认。编辑遇到并发修改而被拒绝时保留草稿，再次打开编辑会继续使用该草稿，直到保存或关闭管理页。目标栏区分持久的 active 状态与本进程的自动继续权限：**Goal waiting** 表示目标已保存，但尚未允许自动继续。恢复会话本身不会授权新一轮执行，需要选择继续目标。轮数已耗尽时禁用继续操作，请先让代理提高上限。

## 后台任务

`/jobs` 打开可搜索的实时列表，运行中的任务排在前面，显示进度、耗时和结束原因。选择任务后可查看输出或停止任务；停止确认默认选择继续运行，并在确认后再次检查任务状态。列表打开期间持续更新，刷新失败时保留上次状态，可选择刷新重试；成功刷新前禁用任务操作。

输出阅读器通过 Harness 的非消费式接口观察 stdout、stderr 和运行叙述，不会推进模型的读取位置。停留在底部时跟随新输出，向上滚动或搜索会固定当前快照，End 恢复跟随。每份快照最多展示最新 约 256K 个字符和 10,000 行，视图截断或后端丢弃输出时明确提示。输出保留由 Harness 管理，不保证进程退出后仍可读取。关闭阅读器会释放订阅，不停止任务；切换会话、卸载插件或取消操作会关闭任务浏览。审批提示优先显示。行模式下，`/jobs <id>` 继续只输出运行叙述，`/jobs kill <id>` 直接请求停止。

## Plan 模式

`/plan` 进入 Plan 模式，`/plan off` 退出。空闲时立即生效，回合运行中则在下一步边界生效。英文状态栏显示当前或待生效的 Plan 状态，目标为 Plan 时空白 composer 提示输入规划任务。Plan 引导模型先调查、提出计划，再实施；它不改变 Access，也不强制文件系统沙箱限制。

模型提交计划后，审核阅读器展示计划原文。PgUp/PgDn 滚动，Tab/Shift+Tab 选择 **批准** 或 **继续规划**，Enter 确认。批准后退出 Plan 并继续执行；继续规划会打开可选的修改意见输入框，可以提交意见，也可以选择 **不附加意见，继续规划**。在意见输入处按 Esc 返回审核并保留草稿；在审核处按 Esc 则不予批准、结束当前回合，保留 Plan 模式等待下一条消息。中断或审核不可用都不会被视为批准。

审核结束、恢复会话或创建包含该调用的分支后，计划仍保存在会话的工具历史中。Ctrl+O 打开已完成的运行，Alt+O 展示完整工具输入和结果。composer 图片和文件可按显示顺序随 `/plan <message>` 发送。`/plan off` 拒绝携带附件，并恢复完整草稿供修改。

## 旁路咨询

`/btw` 使用当前模型与推理设置，在独立的持久会话中回答问题。提问捕获调用时已提交的消息；主会话后续消息及尚未提交的流式文本不在快照中。咨询不能调用工具，恢复后仍受此约束；它从 Read only Access 开始，并清除复制来的 Goal 和 Plan 执行状态，不改变父会话。回复的输出上限为 8,192 tokens。

回答在咨询运行期间流式写入 composer 上方的面板。该面板不属于当前对话——它属于旁路会话，因此没有任何内容写入转录，`Esc` 关闭后 composer 与之前完全一致。`↑`/`↓` 可在面板内滚动。关闭面板会把这次交流折叠成转录里的一行 `/btw <问题>`，答案在 `Ctrl+O` 后面——收回屏幕不会丢掉文字；`/copy` 同样会列出它。Ctrl+C 只中断旁路咨询，父会话的审批优先。建议不会自动发送给主模型：若要让对话接着它继续，用 `Alt+C` 或常用的复制方式引用到 composer。模型请求及复制的输入上下文会单独产生费用；显示的用量只覆盖本次咨询的新请求尝试，不包含继承的历史。咨询自身的会话日志保存在 `OMDSH_HOME` 下。

## 可观测性

| 命令 | 作用 |
|---|---|
| `/context` | 在转录中打印基于 projection 的上下文用量分解，内容会保留在转录里。 |
| `/diff [path\|turn [number]]` | 交互模式逐文件查看当前 Git 改动；`turn` 查看保留的回合快照，不带编号时取最近一次。非交互模式保留文字汇总；不会暂存或提交。 |
| `/trajectory` | 查看会话的事件账本：回合、回合里的步骤与每一步里的记录三层结构、实时跟随、搜索、折叠、每个回合的真实耗时、每条记录的耗时与 token 用量、工具载荷。这是 Harness 事件溯源历史本身的呈现——所有 projection 都从它推导——因此看到的是运行的形状而不只是输出。需要交互式终端。 |
| `/schedule` | 管理本会话的持久提醒：暂停、恢复、立即运行、修改名称或指令、删除，以及浏览投递记录。 |
| `/plugins` | 管理 profile 插件与 bundle：启用、禁用、安装、移除，或从 **Discover** 浏览已配置的插件索引。安装在应用前可取消。 |
| `/tools` | 以转录结果的形式列出 agent 可见的工具。 |
| `/mcp` | 浏览 MCP 注册诊断、可用工具和本会话最近十次调用，并刷新快照。无法提供实时连接和认证状态。 |

### 定时提醒

`/schedule` 列出与当前会话相关的提醒。列表和详情随任务变化刷新；用方向键和 Enter 选择操作，Esc 返回。**立即运行**投递指令，但不改变原定的执行时间。已排队或正在执行的任务不能修改、暂停、恢复、删除或再次触发；页面会说明最短运行间隔及已归档的不可用目标会话。创建提醒、修改时间规则或时区仍通过代理的 `schedule_*` 工具完成。

**查看投递记录**每次加载二十条保存的记录，**加载更早记录**追加下一页。打开一条记录可阅读当时保存的指令、计划与投递时间及目标会话。记录只确认已送达会话收件箱，不代表模型已执行完成。保留期限和缺失的历史指令会明确提示。刷新失败保留已加载记录，**刷新**从最新一页重试。删除提醒须确认，目标会话和已经投递的消息保留。

## 文件与终端

| 命令 | 作用 |
|---|---|
| `/attach [path]` | 流式保存文件，并把引用暂存到 composer，不会直接发送消息；不带路径时列出本会话已存储的附件，其中 **Add a file** 可再暂存一个文件。 |

在输入框中键入 `!command`，即可在持久 Shell 中执行一行命令且输出不会自动进入模型上下文；键入 `!!command` 则在返回时将输出分享到主对话流与会话上下文；详见 [Composer Shell](keyboard.md#composer-shell)。

文件文档支持方向键、PgUp/PgDn 和 Home/End 滚动。`N`/`P` 切换文件，`V` 切换 diff/预览，`O` 打开原件，`E` 使用 Settings 中选定的编辑器，`Q` 将当前阅读位置的 `@path:line` 引用插入 composer。Esc 返回选择器。源码视图分别保留每个文件和 Diff 的阅读位置与搜索词，从编辑器返回后也会恢复。外部编辑器临时接管真实终端，返回后 omdsh 恢复 raw input。

没有文本选区时，右键工具卡片或 Changed files 也会打开同一个阅读器。`Alt+V` 预览阅读位置对应工具声明的文件，否则保留原来的回合比较行为。预览按调用或摘要的原始目录解析路径，读取文件当前内容；提供方声明的行号会在已加载前缀内初始化源码位置。这些操作不提交模型消息、不修改 Access，也不创建文件检查点。

在源码视图按 `/` 或 `Ctrl+F`，对已加载文本进行不区分大小写的字面搜索；Enter 保留搜索词，`Ctrl+N`／`Ctrl+P` 循环跳转匹配行，Esc 取消本次编辑而不关闭阅读器。`G` 或 `Ctrl+G` 跳到文件行号。Diff 显示修改前后的两列行号，跳转使用新文件一侧的行号，`[`／`]` 切换变更块；无法跳到已显示变更块之外的行。文本初次加载 128 KiB，按 `L` 或 **Load more** 将已加载前缀翻倍，最多 4 MiB。超过上限可用 Open 阅读原件；其他二进制格式交给对应应用。

PNG、JPEG、WebP 和 GIF 文件会打开图片预览页。`/attach` 的列表收录用户消息和工具／模型明确输出中存储的图片，并可预览其字节，无需 provider 提供本地路径；`Alt+M` 预览 composer 图片；composer 中没有图片时，打开会话中最新的一张。已识别的直连 Kitty、Ghostty、WezTerm、Warp、Herdr、Rex 和 iTerm2 终端在页面内显示图片；检测有误时可设置 `OMDSH_IMAGE_PROTOCOL=kitty`、`iterm2` 或 `none`，`omdsh doctor` 会报告检测到的协议。tmux、screen、Zellij 和未识别的终端显示图片信息，原图可用时提供 Open 操作。Esc 返回原视图并保留草稿。预览保留宽高比并适配可用单元格，动画图片显示第一帧；解码限制为 32 MiB 和 4000 万像素，预览 PNG 每边最多 2048 px。这些限制不改变原始附件或模型的图片准入规则。

代码预览使用 Prism 语法高亮，颜色跟随所选终端主题。语言根据文件名识别，包括 `Dockerfile` 和 `Makefile`。Markdown 文件默认显示带行号的源码，按 `M` 切换源码与渲染视图；搜索和行号跳转在源码视图中使用。高亮预算内的跨行注释和字符串保留各自的语法颜色，大型预览回退为普通文本。未知语言保持普通文本，关闭颜色后保留源码内容。

用 Tab 或左右方向键选择文档按钮，再按 Enter 执行；`›` 标出当前选项。字母快捷键大小写均可。从工具卡片打开的预览包含同目录文件，供 Previous／Next 切换；只有一个文件时隐藏这两个按钮。`F` 返回文件列表。Open 使用系统默认应用；Editor 使用 `/settings` 的 **Terminal → Editor** 设置，默认自动探测已安装的编辑器。在编辑器中保存并关闭文件即可返回 omdsh。操作失败和外部打开的确认会留在预览页，文件导航不会发送需要关注的通知。

暂存后的 `/attach` 草稿显示文件标记与字节数回执；删除标记即可移除草稿附件。补充消息后按 Enter 一起发送，也支持只发文件。排队消息和回退会保留文件引用。主动输入的斜杠命令通过 Harness 命令准入携带附件，回合运行中也保持命令语义。不接受附件的命令、未知命令以及失败或取消的提交，都会把文本、图片和文件恢复到原会话。粘贴的字面文本和显式 Steer 提交仍作为模型消息。混合附件在重试和队列取回后保留显示顺序。Ctrl+C 取消附件操作；取消后不会暂存草稿。

## 剪贴板与输出

| 命令 | 作用 |
|---|---|
| `/copy` | 在 composer 卡片里选择要复制的内容：最近的助手回复、其中的围栏代码块、最近的 bash 命令与输出，以及已完成的 `/btw` 回答。有选区时 `Alt+C` 会优先复制选区。 |

## Skills

可由用户调用的 Skill 以 `/<name>` 展示，附带技能说明；禁用模型调用的技能标为“仅用户调用”。输入 `/` 和名称可查找技能，提交时可以携带图片和文件。命令与技能同名时，命令优先；可在正文中引用该技能，例如“请用 `/review` 检查这些改动”。见 [Skills 与 MCP](skills-and-mcp.md)。

| 命令 | 作用 |
|---|---|

| `/quit` | 退出应用。别名：`/q`、`/exit`。 |
