# 命令参考

在输入框中键入 `/` 即可打开实时命令补全，支持按命令名、别名、英文描述和中文关键词搜索；`/model`、`/resume` 等命令也会自动补全已有模型和会话。`[方括号]` 表示可选参数，`|` 表示多选一，带选择器的命令通常不传参数直接运行即可。

> 常用阅读器操作（适用于 `/help full`、`/changelog`、`/context` 详情和点击 `[Read]` 打开的长命令输出）：滚轮或 `↑`/`↓`/`PgUp`/`PgDn` 滚动、`/` 页内搜索、`Ctrl+N`/`Ctrl+P` 跳匹配、`S` 选章节、`Y` 复制整页或单个字段、`Esc` 返回。

## 会话

| 命令 | 作用 |
|---|---|
| `/new` | 开启全新空白会话（发第一条消息前可用 `/agent` 选择预设）。 |
| `/resume [会话ID\|关键词]` | 不带参数打开当前目录的会话库；带关键词全文搜索历史会话内容；带 ID 直接恢复。 |
| `/continue` | 续跑因网络/限流中断的模型回复，不重复发原提问（空输入框按 `Alt+R` 等效）。 |
| `/retry` | 带着原来的文字、图片和文件附件重跑上一轮。 |
| `/clear` | 清空当前可见对话并画一条分界线（保留终端上方滚动历史及运行中的队列/Todo）。 |
| `/name <标题>` | 手动重命名当前会话（不会被自动标题覆盖）。 |

## 模型、账号与偏好配置

| 命令 | 作用 |
|---|---|
| `/login` | 登录 DeepSeek 账户、保存 API Key、激活内置服务商或添加自定义 API 服务商。 |
| `/logout` | 退出共享的 DeepSeek 账户，或删除本地保存的服务商密钥（不影响环境变量）。 |
| `/settings`（别名 `/set`） | 在实时状态栏上方打开底部停靠设置面板。 |
| `/permission` | 切换当前会话权限模式（`只读` / `工作区可写` / `完全访问` / `自动审查`），或管理记住的审批规则。 |
| `/agent` | 在空白会话中选择 Agent 预设（Standard / PTC / Minimal / Creator）；`/agent inspect [预设ID]` 查看预设包含的组件；`/agent creator` 直接进入插件开发模式（不改全局默认预设）。 |

### `/model` 全部用法

| 用法 | 效果 |
|---|---|
| `/model` | 打开全部服务商的可搜索模型列表：`Enter` 同时更新全局默认，`Ctrl+D` 仅当前会话生效；`Alt+F` 收藏/取消收藏，`Alt+A` 切换全部/收藏，`Alt+R` 刷新目录。 |
| `/model <关键词>` | 按 `服务商/模型` 或模糊名称匹配；唯一命中直接切换，多条命中打开筛选后的列表。 |
| `/model --session [关键词]` | 仅修改当前会话模型，不改动全局默认。 |
| `/model favorite` / `/model unfavorite` | 把当前模型加入或移出收藏列表（用于 `Ctrl+P` / `Alt+P` 快速轮换）。 |
| `/model favorites` | 打开收藏模型列表。 |
| `/model next` / `/model previous` | 切换到下一个 / 上一个收藏模型。 |
| `/model reasoning` | 循环切换当前模型的推理强度。 |

## 回合控制、长任务与团队协作

| 命令 | 作用 |
|---|---|
| `/plan [off\|<任务描述>]` | 进入计划模式（可附带首个规划请求和附件），`off` 退出。 |
| `/btw <问题>` | 基于当前已提交对话发起一次只读旁路提问，不污染主对话上下文。 |
| `/queue` | 查看、编辑、调序、升级为插话或删除待处理消息（`Alt+Q` 等效）。 |
| `/goal [<目标>\|edit <目标>\|pause\|resume\|clear]` | 设定或管理跨回合长期目标（`Alt+G` 打开管理面板）。 |
| `/team [on\|off\|status]` | 开启/关闭当前会话的 Agent Teams 共享任务板，或用 `/team` 打开交互面板、`/team status` 打印文本总览。 |
| `/jobs [<任务ID>\|kill <任务ID>]` | 浏览后台长任务、实时查看输出日志，或确认停止任务。 |
| `/schedule` | 管理当前会话的定时提醒（暂停、恢复、立即触发、修改、删除与查看投递记录）。 |
| `/questions` | 回答因限时等待而留下的提问（恢复会话后也可用）。 |
| `/compact [保留说明]` | 把早期长对话压缩为精炼摘要；压缩期间可继续排队输入，完成后按 `Ctrl+O` 可回看摘要。 |

### 关键命令详解

- **计划模式（`/plan`）**：模型调研后在方案阅读器中提交计划，你可以选择 **`批准`**（退出计划模式并开始实施）或 **`继续规划`**（输入修改意见，支持 `Ctrl+X` 用外部编辑器撰写）。计划模式只约束工作流，实际文件权限仍由 `/permission` 控制。
- **旁路提问（`/btw`）**：使用当前模型和推理强度在独立只读上下文中作答（不调用工具、单次输出上限 8,192 tokens），流式展示在输入框上方。按 `Esc` 收起后会折叠成一行 `/btw <问题>`，不进入后续主对话上下文，随时可用 `Ctrl+O` 展开或 `/copy` 复制。
- **长期目标（`/goal`）**：按 `Alt+G` 打开管理面板。重启并恢复带未完成目标的会话时，目标栏会停在 **`Goal waiting`** 等待你明确点击继续，避免启动瞬间自动消耗额度。
- **团队模式（`/team`）**：`/team on` 后向主助手和可续跑子智能体开放 `team_task_*` 工具；交互面板实时展示任务状态（`pending (ready)` / `pending (blocked)` / `in progress` / `completed`）、认领者与文件写范围冲突警告，选中任务按 `Enter` 查看完整详情。在子智能体视图下执行 `/team` 会自动解析到根会话。详见[子智能体与团队协作](subagents.md)。
- **后台任务（`/jobs`）**：实时跟随最新约 256 KiB / 10,000 行输出（向上滚动暂停跟随，`End` 恢复跟随），读取输出**不会干扰模型自己消费输出**；停止任务需二次确认。
- **定时提醒（`/schedule`）**：支持即时投递（不改变原定计划时间）及每页 20 条的历史投递记录查看（记录确认已送达会话收件箱，不代表模型已完成执行）。创建新提醒或修改触发周期直接让助手调用 `schedule_*` 工具即可。

## 状态诊断、扩展与工具

| 命令 | 作用 |
|---|---|
| `/context` | 查看 5×8 实时上下文占用网格、估算组成和会话统计，支持打开完整 `详情`、复制会话 ID 或直接 `压缩`。 |
| `/diff [路径\|turn [回合号]]` | 打开交互式 Diff 阅读器查看当前 Git 改动，或用 `/diff turn` 查看某回合快照（非交互模式输出纯文本汇总，绝不自动暂存或提交）。 |
| `/trajectory` | 查看回合、步骤和每次工具调用的耗时、状态、输入、结果与原始事件；支持按耗时排序（`s`）、仅看报错（`e`）和全记录搜索（`/`）。 |
| `/mcp` | 实时添加、启停、探测（`probe`）、重启和移除 MCP 服务器，并查看静态 `mcp.json` 状态、可用工具与本会话最近 10 次调用。 |
| `/plugins` | 浏览插件市场（`发现`）、安装/更新/卸载插件包、管理内置扩展（Codex / Claude Code / Worktree / 自动审查），或启动 `/agent creator`。 |
| `/tools` | 搜索当前对模型可见的所有工具并阅读完整说明。 |

## `/diff`、文件附件与图片阅读器

| 命令 | 作用 |
|---|---|
| `/attach [文件路径]` | 将文件附加到当前草稿（不立即发送）；不带路径时列出本会话已存储的附件并可预览图片。 |

在空输入框输入 `!命令` 可直接在持久 Shell 中运行命令（`!!命令` 会将结果分享给模型），详见[快捷键与鼠标](keyboard.md#快捷-shellcommand-与-command)。

### Diff 与源码阅读器操作

- **布局**：终端宽度 ≥ 100 列时自动双栏（左文件列表、右对比内容），窄屏单栏；`Tab` 切栏，`Enter` 阅读，`A` 打开操作菜单，`?` 看帮助。
- **视图切换与导航**：`V` 在“增删对比”和“当前完整文件”间切换；`[` / `]` 跳变更块；`/` 或 `Ctrl+F` 搜索（`Ctrl+N`/`Ctrl+P` 跳命中）；`G` 跳行号；`W` 切折行，`Alt+←`/`Alt+→` 横向平移；Markdown 文件按 `M` 切源码/渲染视图。
- **大文件保护**：文本初次加载 128 KiB，按 `L`（`Load more`）翻倍加载至最多 4 MiB；超限或二进制文件按 `O` 用系统应用打开，按 `E` 用设置的外部编辑器打开。
- **直接引用回输入框**：选中任意几行后按 **`Alt+Y`** 或 **`Q`**，直接把选区作为 Markdown 引用插回输入框（无选区时 `Q` 插入 `@路径:行号`）。

### 图片预览与附件规则

- 按 **`Alt+M`** 预览草稿图片（无草稿图片时打开会话最新一张），或在 `/attach` 中浏览已存图片；支持 PNG、JPEG、WebP、GIF。
- 在直连的 Kitty、Ghostty、WezTerm、Warp、iTerm2 等终端中直接内联显示图片；在 tmux / screen / Zellij 等未支持的环境中可点 **`打开`** 用系统看图器打开。可通过 `OMDSH_IMAGE_PROTOCOL=kitty|iterm2|none` 覆盖自动检测。
- 预览解码上限为 32 MiB / 4000 万像素（单边最多 2048 px）；模型发送端单图上限 20 MiB。

## 剪贴板、导出、Skills 与应用

| 命令 | 作用 |
|---|---|
| `/copy` | 选择复制最近的助手回复、其中的单个代码块、最近的终端命令输出或已完成的 `/btw` 回答（有选区时 `Alt+C` 优先复制选区）。 |
| `/export [markdown\|html\|archive] [路径]` | 导出当前会话为 Markdown、HTML 或含子智能体与原图的 ZIP 归档（不覆盖已有文件）。 |
| `/changelog [full]` | 按版本浏览更新日志（`S` 选分类）；`full` 查看完整历史。 |
| `/<技能名>` | 调用已发现的项目或个人 Skill（可携带图片和文件）；与内置命令同名时内置命令优先。详见 [Skills 与 MCP](skills-and-mcp.md)。 |
| `/help [full]`（别名 `/h`、`/?`） | 搜索并填入命令；`Alt+K` 或 `full` 查看当前生效的全部快捷键。 |
| `/quit`（别名 `/q`、`/exit`） | 退出 omdsh。 |
