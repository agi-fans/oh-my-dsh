# 权限与安全

在 omdsh 中，每次会话都有一个明确的**权限模式**（界面英文称 `Access`），它同时约束文件读写与 Shell 命令的沙箱范围，并决定越界操作何时弹窗向你确认。

- 运行 `/permission` 切换**当前会话**的权限模式；
- 在 `/settings` 的 **`常规` → `默认权限`（`Default access`）** 中设置新会话的默认权限（也可通过环境变量 `OMDSH_PERMISSION_MODE` 指定部署默认值）。

## 四种权限模式怎么选

| 权限模式（中文 / 英文） | 沙箱级别 | 是否询问确认 | 推荐场景 |
|---|---|---|---|
| **`只读`** / `Read only` | `read-only` | 越界时询问 | 刚接手陌生仓库、做安全审计或纯阅读分析，确保不会意外改文件。 |
| **`工作区可写`** / `Workspace write`（默认） | `workspace-write` | 越界时询问 | **绝大多数日常开发**。允许在当前工作区内自由读写和跑测试，触及工作区外或危险操作时弹窗确认。 |
| **`完全访问`** / `Full access` | `danger-full-access` | 从不询问 | 容器、一次性开发机或你完全信任的自动化任务。 |
| **`自动审查`** / `Auto review`（仅限当前会话） | 无文件系统沙箱 + 执行前模型审查 | 审查拦截时询问 | 希望减少频繁手点确认，同时在写操作或外部调用前增加一道自动安全审查。 |

### 几个实用细节与常见误区

- **工作区外写操作不会悄悄失败**：在 `只读` 或 `工作区可写` 下，文件工具和 Shell 共用同一套沙箱规则。若模型试图改动工作区外的文件（例如 `~/.ssh` 或其他目录），操作会被沙箱拦截，模型可请求你审批后以更宽权限重试一次；审批通过后，输入框旁的权限徽标会实时显示当前实际生效的模式。
- **关于 `自动审查`（`Auto review`）**：由随包默认启用的内置扩展 `@deepseek-ai/dsh-experimental-auto-review` 提供（不需要时可在 `/plugins` → `插件包` 里禁用）。它不会出现在全局 `默认权限` 中，每次需在 `/permission` 里确认开启。需注意两点：
1. 审查过程会增加额外的模型调用和延迟；
2. 如果使用 `code`（PTC）预设，在 `run_code` 里直接发起的 Node 副作用不受内部工具审查约束。
- **常见误区：开了 `/plan` 为什么权限还是 `工作区可写`？** `/plan` 是工作流模式（指导模型先调研出方案再动工），真正的读写安全边界始终由 `/permission` 负责。
- **常见误区：切换子目录会不会扩大权限？** 不会，沙箱边界绑定在会话启动时的原始工作区。

## 审批弹窗如何工作

当某个操作超出当前沙箱范围时，底部会弹出带有**警告色边框**的审批卡片：

- 卡片先展示即将执行的工具详情（具体命令、目标路径或改动摘要），再显示提问理由；
- 审批卡片会优先于普通阅读浮层（例如 `/trajectory` 或 `/settings`）弹出，你处理完审批后会自动回到刚才的界面，避免在过期界面上误点；
- 当多个子智能体同时请求审批时，卡片会按顺序逐个呈现，并标明是哪一个子智能体发起的；
- 切换当前会话时，原会话未处理的审批（含其子智能体的审批）会被自动取消，不会在后台意外放行。

## 记住审批决定（精确匹配规则）

在审批卡片上，你可以选择 **`记住允许`（`Remember allow`）** 或 **`记住拒绝`（`Remember reject`）**，并限定作用域为 **`仅当前会话`** 或 **`当前工作区`**：

- **当前会话规则**：恢复该会话后继续生效，但不会自动传给分叉的新会话或子智能体；
- **当前工作区规则**：对同一个工作区下的所有会话（含子会话）都生效；
- 随时运行 `/permission` → **`审批规则`（`Approval rules`）** 可以查看和撤销已记住的规则（撤销只影响后续请求，不中止已经在跑的操作）。

### 匹配规则非常严格（按精确调用匹配）

为了防止“放行一次误放行一片”，记住的规则要求以下 6 项**全部完全一致**才会命中：工具名、完整参数 JSON、当前工作目录、原始工作区、当前权限模式、审批理由。

- **举例**：你记住了允许运行 `git status`，下一次模型运行 `git status -s` 时**依然会弹窗询问**，因为命令字符串不完全相同（不支持通配符或前缀匹配）；
- **安全边界**：记住的规则不能突破系统级禁止策略或硬性沙箱限制，也不会永久放宽权限模式；单条规则的参数或理由超过 64 KiB 时不可保存，最多保存 500 条；规则存放在 `$OMDSH_HOME/omdsh/approval-rules/`。

## Shell 执行超时与资源限制

omdsh 按平台挂载受限 Shell（macOS / Linux 为 Bash，Windows 为 PowerShell），默认单条命令超时为 120 秒。如需调大超时、输出上限或结束宽限时间，前往 `/settings` → **`插件` → `Shell`**。长时间运行在后台的命令可随时在 `/jobs` 中查看或停止。
