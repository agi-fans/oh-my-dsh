# 键盘与快捷键

`/help` 会在命令列表旁打印实时快捷键目录，`/help full` 补全完整版本；目录显示的是当前实际生效的绑定。应用级绑定可以通过 `keybindings.json` 覆盖，编辑器本身保留一套固定的类 Vi 按键。

## 光标导航

| 快捷键 | 作用 |
|---|---|
| 方向键 | 移动光标；composer 为空时浏览输入历史。 |
| `Ctrl+A` / `Home` | 移到行首。 |
| `Ctrl+E` / `End` | 移到行尾。 |
| `Alt+B` / `Alt+Left` | 左移一个词。 |
| `Alt+F` / `Alt+Right` | 右移一个词。 |
| `Ctrl+]` 后接一个字符 | 向前跳到该字符。 |
| `Ctrl+Alt+]` 后接一个字符 | 向后跳到该字符。 |

## 编辑

| 快捷键 | 作用 |
|---|---|
| `Enter` | 发送消息。 |
| `Shift+Enter` / `Ctrl+J` | 插入换行。 |
| `Ctrl+W` / `Alt+Backspace` | 删除前一个词。 |
| `Alt+D` | 删除后一个词。 |
| `Ctrl+U` | 删除到行首。 |
| `Ctrl+K` | 删除到行尾。 |
| `Ctrl+Y` | 粘贴回已删除的文本。 |
| `Alt+Y` | 在删除环中循环。 |
| `Ctrl+-` | 撤销上一次编辑，或恢复刚清空的草稿。 |
| `Ctrl+D` | 向后删除；composer 为空时退出。 |
| `Ctrl+V` | 粘贴剪贴板文本或图片。 |
| `Alt+M` | 预览 composer 图片，不发送消息；没有草稿图片时，打开会话中最新的一张图片。 |
| `Alt+I` | 展开折叠的粘贴内容进行编辑。 |
| `Alt+Up` | composer 为空时，撤回最近一条排队消息以便编辑；Enter 会重新提交。 |
| `Alt+G` | 管理当前目标，不提交输入框草稿。 |
| `Alt+Q` | 打开消息队列，保留 composer 中的草稿。 |
| `Ctrl+S` | 暂存或恢复当前 composer 草稿；发送一条消息后会自动恢复暂存的草稿。 |
| `Alt+S` | 将草稿连同图片和文件送到当前 Turn 的下一次模型步骤。 |
| `Alt+Enter` | 把当前草稿排到活动回合之后，不受运行时 Enter 行为设置影响。 |
| `Alt+C` | 复制选中文字；没有选区时复制当前提示。 |
| `Ctrl+Alt+C` | 复制当前行。 |
| `Ctrl+X` / `Ctrl+G` | 在 Settings 选定的编辑器中编辑提示。 |

超过十行或 1,000 个字符的粘贴内容显示为 `[Pasted #1: 120 lines]` 或字符数标记。方向键和删除操作将每段内容视为一个整体；`Alt+I` 展开光标所在或附近的粘贴块进行编辑，`Ctrl+-` 可撤销插入、删除或展开。复制提示、使用外部编辑器和发送消息时均使用完整文本。临时问答和队列消息编辑保留原文。以折叠粘贴块开头的草稿会作为模型消息发送，即使原文以 `/` 开头。用 `Alt+Enter` 排队的草稿会在 composer 上方标记为 `Queue · next turn`（排队 · 下一回合），`Alt+Up` 可把它取回编辑。

**Paste protection** 还会在终端未标记粘贴输入时识别大段文本、一次读取中的多行内容和快速 ASCII 按键流，避免其中的 Enter 提前提交消息。粘贴结束后稍等，再按 Enter 发送。普通输入和单次输入法提交立即显示。这属于启发式识别；如果影响你使用的终端，可在 Settings 中关闭。关闭后，明确标记的 bracketed paste 仍然不会触发误提交。

## 转录

回合运行时，思考和工具调用默认各占一行，以折叠箭头标明可展开。回复使用普通 Markdown；失败调用保留原因。展开思考后显示淡色斜体正文；展开工具后在中性底色上显示带水平和垂直留白的可读内容。终端输出保持纯文本；明确识别语言的源文件保留语法高亮，Read 行号独立对齐，正文换行不会挤占行号列；Alt+O 提供完整的 Input 与 Output。活动、重试与压缩状态放在 composer 上边框，临时确认放在下边框。回合结束后，过程收为 `Worked for 16s` 这样的摘要，所有助手回复和失败原因继续可见。正在检视的内容保持展开，直到读者返回实时底部。

当表格列在窄屏上难以阅读时，会改为带列名的逐条记录。完整且能够容纳的 Mermaid 图形用终端字符绘制；不支持、不完整或尺寸过大的图形保留为代码原文。[Settings](settings.md) 中的 **Mermaid in replies** 可以切换 Auto 和 Source。回复公式遵循 [Settings](settings.md) 中的 **Math in replies** 设置。 **Thinking in turns** 默认折叠，以单行 `Thinking · …` 预览最新段落。流式生成时，只有首行完整的段落才进入预览，同段后续文字不会改变预览。已有的显式 Shown 偏好继续生效；`Ctrl+T` 切换默认展示，单项仍可独立展开或收起。

`Ctrl+O` 进入视口所在回合的过程浏览，运行中和已完成回合均支持。`↑`/`↓` 选择单项，`Enter` 切换可读内容，`←`/`→` 收起或展开。`Home` 回到正在阅读的工具标题；当前视口不在工具详情内时，回到选中项标题。同一次过程浏览中，收起再展开工具会恢复阅读位置；终端宽度或详情格式变化后则回到标题。命令展示命令和输出，读取文件展示内容，编辑展示 Diff，搜索展示位置与匹配片段。`Esc`、`Ctrl+O` 或 `End` 返回实时底部并重置展开状态；输入或粘贴文字会把焦点交回 composer，同时保留过程视图和草稿。`Alt+O` 一次展开当前回合所有工具的完整参数与结果，包括 PTC 子调用和运行中新到达的调用；再按一次恢复紧凑行。向下滚过末尾也会关闭检视。展开详情不改写终端原生历史。视口位于压缩提示时，`Ctrl+O` 则展开已保存的摘要。

详情展示 TUI 已收到的全部文本，无法恢复工具已经截断或溢出到文件的内容。`/trajectory` 提供事件级检查，`Ctrl+Shift+F` 会搜索预览之外的内容并显示命中位置；composer 为空时 `Ctrl+F` 等效，非空时仍用于移动光标。

浏览上方消息时，composer 区域上方会出现 `↓ Latest · End` 浮层。用户消息滚出视口后，顶部会固定显示一行摘要，并随当前阅读的回合切换。滚动进入展开的工具结果后，顶部同一行改为显示工具标题；离开该工具详情后恢复提问摘要。这些内容只属于视口控件，不属于对话正文。

| 快捷键 | 作用 |
|---|---|
| `PgUp` / `PgDn` | 翻一页。 |
| `Shift+Up` / `Shift+Down` | 快速滚动。 |
| 鼠标滚轮 | 从实时底部或回合检视中滚动转录，无需先展开回合。 |
| `End` / 点击跳转浮层 | 回到最新消息并关闭回合详情。在实时底部，`End` 仍移动到 composer 当前行末尾。 |
| `Ctrl+O` | 浏览运行中或已完成回合：↑/↓ 选择、Enter 展开、←/→ 收起或展开、Home 回到标题、Esc 返回。再按一次回到实时底部；在工具目录上切换描述详略。 |
| `Alt+O` | 切换当前阅读回合的完整工具输入和结果，运行中的回合也可使用。 |
| `Alt+A` | 打开当前工具的操作菜单：复制命令、复制结果或查看声明的文件。 |
| `Alt+Y` | 将选中文字作为 Markdown 引用追加到草稿，不自动发送。 |
| `Alt+V` | 预览阅读位置所在工具声明的文件。该位置没有工具时会说明并指向 `/diff`，由它审查本回合的改动。 |
| `Ctrl+Shift+F` | 搜索当前转录；`n`/`N` 在匹配间跳转。composer 为空时 `Ctrl+F` 等效，非空时移动光标。 |
| `Ctrl+T` | 显示或折叠整个转录中的思考。 |

转录可以滚动，或包含展开箭头、可操作文件时，折叠和展开视图都支持在当前视口内拖选文字。双击选择单词或路径，三击选择整行，Shift 点击扩展选区；默认松开鼠标后复制。可在 Settings 关闭 **Copy on select**，改用 `Alt+C`、`Enter` 或右键复制；`Esc` 清除选区，`Ctrl+C` 保留清空与中断行为。输入框可写时，`Alt+Y` 将选区作为 Markdown 引用块追加到草稿，保留已有文字和附件，不自动发送。一次撤销即可移除引用；较长的引用与粘贴文字一样折叠显示。滚动、调整窗口、输入文字或所选行内容变化时会清除选区。

点击过程行左侧的箭头可展开或收起内容；点击已完成回合的箭头可进入过程浏览。标题之前的左侧区域都可点击，包括箭头与周围留白。区域内的小幅移动和预览更新不会取消点击。标题和路径仍可选中复制；拖出点击区后只选择文字，即使移回箭头也不会切换展开；Shift 点击继续扩展选区。键盘可从点击的项目继续导航。

选中的工具行还提供 `[···]` 按钮，打开相同的操作菜单，并显示对应命令或文件。选中文字后，输入框下方会在空间足够时显示 `[复制]` 和 `[引用]`。点击保留草稿和阅读位置，拖出按钮会取消点击；复制和引用的反馈会暂时替代导航提示。

Read 结果保留连续源码范围时，**复制源码** 会复制该范围，去掉显示用的行号和折行；**引用源码** 将文件、行号范围及代码围栏追加到草稿。两者都使用原调用保留的内容，保留缩进和长行，不会重新读取可能已变化的文件，也无法恢复工具未返回的内容。只读视图仅提供复制。

没有文本选区时，右键带文件位置声明的工具卡片可预览其文件，右键 Changed files 的文件行可直接预览该文件。阅读器复用 Open 和已配置的 Editor。工具的相对路径保留调用发生时的目录；Changed files 保留摘要所属目录。这些预览展示宿主文件的当前内容。`Alt+V` 打开的是阅读位置所在工具的同一批文件；已完成的回合摘要不会使隐藏的工具卡片变成点击目标。搜索工具按文件和行号列出每个声明的命中，并附上匹配文字；同一文件中的不同命中也可分别选择，打开后定位到对应行。阅读器会在 4 MiB 预览上限内加载足够的内容以到达该行；文件可能已在搜索后发生变化。`Alt+A` 的当前工具菜单也提供这些文件入口以及复制操作。关闭菜单或阅读器会保留草稿和对话阅读位置。审查回合改动由 `/diff` 负责。Native 鼠标模式保留键盘入口。审批或其他用户提问会取消文件操作，避免争抢输入。

**Mouse interaction** 默认 `auto`，尊重 tmux 的 mouse off 设置；`tui` 显式启用应用接管，`native` 将鼠标交给终端，键盘滚动和 `End` 仍然可用。终端原生历史继续保留，可用终端选择或 tmux copy-mode 复制。

全屏页面暂时关闭应用鼠标接管。`/trajectory` 等浏览界面关闭后恢复原来的检视位置；命令返回转录文本时，会回到实时底部显示结果。

文件和 Diff 的源码阅读器用 `/` 或 `Ctrl+F` 搜索已加载文本，`Ctrl+N`／`Ctrl+P` 循环跳转匹配行，`G` 或 `Ctrl+G` 跳到文件行号。`[`／`]` 切换 Diff 变更块；提供相应按钮时，`L` 加载更多文本，`Q` 将 `@path:line` 插入 composer，`M` 切换 Markdown 渲染。Enter 应用搜索或行号输入，Esc 先取消输入，再返回文件列表。预览上限和视图行为见[文件命令](commands.md)。

源码阅读器默认将长行折行。`W` 切换折行；`Alt+Left`／`Alt+Right` 横向移动八个显示单元格，并切换为不折行模式。行号保持固定，阅读器操作之间保留折行状态和横向位置。普通左右方向键仍用于选择操作按钮；后台任务输出沿用相同的阅读快捷键。

| `Alt+R` | 输入框为空时，继续可恢复的失败生成。 |
| `Ctrl+L` | 选择模型和推理强度。 |

| Session Library | 清空搜索后 `p` 置顶／取消置顶、`r` 重命名；`Alt+A` 归档／恢复选中会话，`Alt+V` 切换默认／归档列表，列表为空或正在搜索时也可切换。 |

可搜索的选择列表支持多词查询，例如 `official flash`；每个词都必须匹配名称、标识符、预览或描述中的内容。`flsh` 这样的短缩写可以在单词内部匹配。名称的完整匹配和前缀匹配排在仅描述匹配之前，清空查询会恢复原始顺序。这些规则用于选择器筛选；转录搜索、提示历史和 `/resume <query>` 保留各自的搜索规则。

## 自定义键位

应用级绑定存放在 `$OMDSH_HOME/omdsh/keybindings.json`（回退到 `$DSH_HOME`，再到 `~/.dsh`），与会话、设置和 MCP 文件使用同一个 home。你可以在 `/settings` 的 **Terminal → Input → Keybindings** 中交互式重绑或解绑快捷键（保存后立即生效），也可以直接编辑 JSON 文件：

```json
{
  "ctrl+j": "search-transcript",
  "ctrl+r": "retry",
  "ctrl+s": null
}
```

key id 用 `+` 连接修饰键（`ctrl`、`alt`、`shift`、`super`），具名键用小写拼写（`pageup`、`pagedown`、`escape`、`left`、`right`、`up`、`down`）。值必须是下表中的 action id，或用 `null` 解除默认按键绑定；无法识别的 action 或格式错误的文件只会让对应条目保留出厂绑定。`/help` 会显示实际生效的按键。

快捷键中的 **测试按键** 显示终端实际发送的文本或按键序列，以及已绑定的应用操作。测试不会执行快捷键、修改草稿或保存绑定；`Esc` 或 `Ctrl+C` 返回。支持 `F1`–`F12` 的标准终端编码及修饰键，例如 `"f6": "tool-actions"`。终端或操作系统可能在 omdsh 收到按键前将其拦截。macOS 的 Option 也可能输入 `å`、`¥` 等字符；它们仍是普通文本。可换一个绑定，或调整终端的 Option/Alt 设置后再测试。

| Action id | 默认键 | 作用 |

## Composer Shell

在输入框中键入 `!command`，即可在当前会话的持久 Shell 中执行一行命令；键入 `!!command` 则在命令结束时把输出分享到主对话流与会话上下文。草稿以 `!` 开头时 composer 边框立即变绿，所以在决定执行之前就能看到当前处于 Shell 模式。Shell 使用当前 Access 级别，从当前工作目录启动，后续调用保留它自己的目录和环境变量。它与 Agent 的工具 Shell 相互独立。

输出作为一张卡片流式出现在命令下方，命令结束时就地定型——没有阅读页需要打开或退出。`Ctrl+C` 中断正在运行的命令。`!command` 的输出不进入模型上下文；`!!command` 在命令结束时把输出分享到对话。执行仍受当前 Access 级别约束。

Shell 历史和环境仅保留在当前运行的 Agent 中；恢复已保存的会话会创建新 Shell。带粘贴标记且以 `!` 开头的文本仍作为普通消息处理。需要执行时，请主动键入开头的 `!`；无标记的单行粘贴有时无法与键入区分。携带附件的输入仍按消息处理。快捷执行需要交互式终端；Shell 返回控制权不代表命令已退出。
