# 调好终端与模型偏好

omdsh 开箱即用的默认配置已经能覆盖大多数场景。如果你想微调配色、精简或丰富状态栏、收藏几个常用模型，或者在 tmux / 浅色终端里获得更顺手的体验，按这篇调一次即可。

## 打开底部停靠的 `/settings` 面板

输入 `/settings` 并按 `Enter`。设置面板会**停靠在输入框的位置、实时状态栏的正上方**，而不是铺满全屏——上方依然能看到对话记录，下方依然是真实的状态栏。

面板顶部按 5 个常用标签分组（当安装了带额外配置项的第三方插件时，才会出现第 6 个 `高级` 标签）：

| 标签页（中文 / 英文） | 负责什么 |
|---|---|
| `常规` / `General` | 界面语言、更新提示、启动版本说明 |
| `模型` / `Models` | DeepSeek 账户、其他模型服务商与自定义 API |
| `Agent 预设` / `Agent presets` | 新会话默认使用的预设模式（标准、PTC 代码模式等） |
| `插件` / `Plugins` | 内置能力（文件恢复快照、Tmux 上下文、自动审查、MCP、Codex/Claude 集成等）与第三方插件配置 |
| `终端` / `Terminal` | 主题、动画、鼠标交互、快捷键、状态栏、通知与输入行为 |

在面板里操作非常直接：

- `←` / `→` 或 `Tab` 切换标签，`↑` / `↓` 移动光标，`Space` 或 `Enter` 切换开关；
- 按 `/` 可以直接按关键词搜索任意设置项，输入时光标可见，按 `Esc` 清空搜索词；
- 外观、状态栏等终端偏好**改动立即生效并自动保存**，底部会闪现一行短暂确认，不污染你的对话记录；涉及 Shell、子智能体、模型服务商等多字段表单时，改完后选 `应用` 一次保存。

## 按场景推荐的终端调整

不需要把几十项设置全看一遍，根据你的使用环境重点看这 5 项即可：

### 1. 配色与界面语言

- **主题**（`终端 → 主题`）：提供 `深色`（Catppuccin Mocha）、`浅色`（Catppuccin Latte）与 `跟随系统`（自动读取终端背景）。如果你用自定义配色方案且希望完全贴合终端，选 `跟随系统`。
- **界面语言**（`常规 → 语言`）：默认为 `自动`（中文系统自动显示简体中文，其他环境显示英文），也可以固定为 `简体中文` 或 `English`。

### 2. 实时定制底部状态栏

在 `终端 → 状态栏` 中调整任何一项时，**面板正下方的真实状态栏会实时同步变化，并对当前光标选中的指标加下划线高亮**，所见即所得：

- **信息密度（`密度`）**：
- `minimal`（精简）：只看上下文占用；
- `standard`（标准，推荐）：增加缓存命中率、首字延迟和输出速度；
- `verbose`（详细）：使用完整标签，在屏幕足够宽时会多出一行显示整个会话的累计轮次与耗时。
- **单项开关**：可以单独隐藏不需要的路径、Git 分支、会话标题或指标，按 `Ctrl+R` 可随时恢复继承默认值。
- 底部状态栏的指标标签（如 `Ctx`、`Cache`、`TTFT`）在所有语言下都保持英文，避免切语言时宽度跳动。

### 3. tmux / 鼠标选字习惯

如果你经常在终端里直接用鼠标拖选复制文字，可以在 `终端 → 鼠标交互` 中三选一：

| 选项 | 适用习惯 |
|---|---|
| `自动`（默认） | 滚轮滚动界面、点击展开折叠块与按钮；需要原生拖选复制时按住 `Shift`（或 `Option`）。 |
| `开启` | 强制启用界面内滚轮和点击。 |
| `关闭` | 完全交还给终端原生鼠标选择，适合习惯直接拖拽复制且主要用键盘导航的用户。 |

### 4. 长任务桌面通知

在 `终端 → 通知` 中开启通知后，当你切到浏览器或其他窗口时，只要长任务完成或出现需要你确认的审批弹窗，终端就会发送系统通知提醒你切回来（默认关闭）。

### 5. 外部编辑器

写很长的需求或修改计划意见时，可以按 `Ctrl+X` 唤起外部编辑器。omdsh 默认读取环境变量 `$VISUAL` 或 `$EDITOR`，你也可以在 `终端 → 外部编辑器` 里直接指定（如 `code --wait`、`nvim`、`vim`）。

## 收藏常用模型与调整推理强度

日常写代码往往会在“响应极快的轻量模型”和“深度思考的强模型”之间切换，不必每次都重新在 `/model` 列表里翻找：

1. **收藏高频模型**：运行 `/model favorite` 把当前模型加入收藏列表（`/model unfavorite` 移出）。之后随时按 `Ctrl+P` / `Alt+P` 就能在收藏的模型间循环切换。
2. **区分“改全局默认”和“仅当前会话”**：在 `/model` 里直接按 `Enter` 会同时更新新会话的默认模型；如果只想在这一次对话里临时换模型，按 `Ctrl+D` 选择 `仅当前会话`（`This session only`）。
3. **随时切换推理强度**：按 `Shift+Tab` 在可用的推理档位间切换，结果实时显示在底部状态栏左侧：
- 简单检索、改个文案或小修补：调低推理强度，响应更快、消耗更少；
- 复杂重构、定位疑难 Bug 或设计方案：调高推理强度，让模型充分推演。
4. **控制思考过程是否展示**：按 `Ctrl+T` 切换是否显示模型的思考块。

## 接入其他模型服务商

除了 DeepSeek，你也可以在 `/login` 或 `设置 → 模型` 中接入其他兼容 OpenAI / Anthropic 协议的服务商：

- 选择内置服务商列表里的任意一项，粘贴 API Key 即可激活；
- 如果使用自建网关或私有部署端点，在 `/login` 中选择添加自定义服务商，依次填写服务商名称、Base URL、协议类型（OpenAI Chat Completions / OpenAI Responses / Anthropic Messages）和模型 ID 即可。

## 遇到环境异常怎么办

如果启动报错、模型列表为空或登录状态异常，先在终端运行一次内置自检命令：

```sh
omdsh doctor
```

它会逐项检查运行环境、登录凭据、配置文件和已安装的插件状态，并直接给出可执行的修复提示。详细排查步骤见[故障排查](../troubleshooting.md)。
