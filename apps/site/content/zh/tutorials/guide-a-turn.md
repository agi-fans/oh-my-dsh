# 引导运行中的任务

读完本教程，你可以排队后续消息、进入 Plan mode，并查看任务进度。

### 将后续消息加入队列

继续一个运行中的任务不需要特殊命令。默认情况下，在 `Deep Driving` 状态下按 Enter 会将普通消息放入 next-turn 队列，队列显示在 Composer 正上方。设置 → 终端 → 输入 → 运行时 Enter 行为可以将 Enter 改为插话。输入框会提示当前行为；排队和插话快捷键的含义保持固定。

要在队列消息执行前修正它：在空 Composer 中按 `Up` 选中最新一条队列消息（再按 `Up` 可向更早的消息移动），修改文本后按 `Enter` 放回队列。整个过程不会中断当前工具调用。

如果想纠正当前任务，可输入指导文本后按 `Alt+S`。Harness 会在下一次模型步骤前接收它，不会中断正在执行的工具调用。**插话 · 下一步** 保留到消息被取出；**排队 · 下一回合** 则等待当前 Turn 结束。两种投递方式均支持文本、图片和文件，保留图片位置和文件顺序。`Alt+Enter` 始终排队（Windows 还可使用 `Ctrl+Q`），`Alt+S` 始终插话。投递方式在提交时固定，修改偏好不会改变待处理消息的去向。提交失败时完整内容恢复为未发送草稿，不会自动重试；若保存附件期间回合结束，插话会恢复到输入框，不会悄悄启动新回合。空闲时的 Enter、命令和取回后的队列编辑保持原有行为。

按 Esc，或在空 composer 中按 Ctrl+C，会中断当前回合。已接收的排队和插话消息连同附件在会话仍挂载时继续保留；停止不会撤回或重复提交这些消息。可通过 `/queue` 编辑或撤回。在退出时间窗口内再次按 `Ctrl+C` 会离开 omdsh，因此如果还要继续当前会话，请不要立刻重复按键。

使用 `/queue` 或 `Alt+Q` 逐条管理待处理消息。实时列表区分 **插话 · 下一步**、**排队 · 下一回合** 和 **发送中 · 尚未接收**。标签和控件随界面语言切换，消息原文保持不变。输入文字可以筛选，方向键或 Tab 选择条目；Enter 编辑文本并保留图片和文件引用。回合运行时，`Alt+S` 将选中的已接收排队消息转为插话，保留原文字、图片和文件引用。发送中或已在插话组的消息不能转换；回合已停止时，消息仍保留在队列中。`Alt+D` 撤回一条，`Alt+↑`/`Alt+↓` 在同组内调整顺序，不跨越插件拥有的队列消息。Esc 取消，保留 composer 草稿和已接收的消息。

当前固定版本的 Harness 会在销毁 Agent handle 时清空待处理 inbox。因此，正常退出和切换会话后的清理不会保留队列供 resume 恢复。未被清空的日志可以重建待处理 inbox，但这不代表正常退出后能恢复队列。Composer 草稿和 Harness 尚未接收的输入单独保存。重启后，本地待发送输入显示为 **已恢复 · 确认后发送**，等待你确认。打开 `/queue`，选中条目并按 `Alt+R` 发送，或取回 composer 修改后提交。已记录为接收成功的消息会按 Harness 消息 ID 排除。命令或子代理投递可能在本地确认保存前已经完成，重新发送恢复内容前应核对会话记录。恢复不会自动重放命令或 Shell 操作。

工具问答优先于队列页面。若编辑被问答打断，修改后的文本会回到 composer 作为未发送草稿，原队列条目保持不变。若模型在保存编辑之前取走原消息，修改内容同样还原为草稿，不会自动创建另一条消息。插话和排队消息的修改由 Harness inbox 持久化。Harness 尚未接收的输入保存在原会话的本地恢复文件中，包括文本、附件、顺序和投递方式。若切换会话打断编辑，修改文本和附件会保存为原会话的草稿。Harness 取出待处理消息时，composer 会短暂显示确认；这不表示模型已经回答。

### 修改文件前先制定计划

对于需要先调查再提出实现方案的任务，运行 `/plan`。Plan mode 会指导模型先进行只读检查，再通过审批流程提交可审阅的计划。

- `/plan <message>` 在进入 Plan mode 的同时发送第一条规划要求。
- `/plan off` 直接退出 Plan mode。

Composer 中的图片会随 `/plan` 和 `/goal` 一起提交（当这些命令接受附件时）；`/plan off` 以及其他不能使用图片的子命令会把草稿退回 Composer。

### 跟踪任务进度

当 Agent 写入 Todo 列表后，Composer 和队列上方会出现紧凑的任务树，分别表示已完成、当前和待处理工作。任务树就是列表本身，不再提供把已过时副本打印进 Transcript 的命令。

Todo 描述当前回合的工作，而 `/goal <objective>` 用于控制更长时间运行的目标。不带参数运行 `/goal` 可以查看当前状态和可用操作。被委派的子代理会出现在 composer 上方的 roster 中，按 `↓` 选中、`Enter` 打开其转录；[子智能体与委派](../subagents.md)介绍了三种 transport 以及如何引导可继续的孩子。
