# 快速上手：完成第一个改动

这篇教程带你从零跑通一次完整的终端编程闭环：安装启动、登录选模型、先让助手读项目、再让它做一个小改动，最后用 `/diff` 审查改动结果。整个过程大约 5 分钟。

## 准备环境与安装

开始前确认本地满足以下条件：

- Node.js 24.22.3+（24.x）或 Node.js 26.13.1+（可用 `node -v` 检查）
- 一个支持交互的终端（macOS Terminal / iTerm2 / Ghostty / Kitty / WezTerm / Windows Terminal 等均可）
- 一个 DeepSeek 账户，或一个可用的 DeepSeek API Key（也支持其他模型服务商）

全局安装后，进入任意一个你想尝试的项目目录启动：

```sh
npm install --global @agi-fans/oh-my-dsh
cd /path/to/your-project
omdsh
```

如果只是临时试用、不想全局安装，也可以直接运行 `npx @agi-fans/oh-my-dsh`。

启动后你会看到三块区域：顶部是欢迎标识，中间是对话记录区，最下方是固定不动的**输入框**（`🐳`）和**底部状态栏**（显示当前模型、推理强度、工作目录、Git 分支和上下文占用）。

## 登录并选择模型

首次使用需要配置一次模型认证。在输入框中输入 `/login` 并按 `Enter`：

1. **使用 DeepSeek 账户（推荐）**：选择 `DeepSeek 账户`（英文界面为 `DeepSeek account`），浏览器会自动打开授权页，确认后即登录成功。如果你之前已经登录过 DSH 网页版或桌面端，omdsh 会自动复用登录状态，无需重复授权。
2. **使用 API Key**：选择 `DeepSeek`，按提示粘贴你的 API Key，验证通过后会加密保存在本地凭据文件中。如果你习惯用环境变量，也可以在启动前设置 `DEEPSEEK_API_KEY`。

登录完成后，运行 `/model` 选择一个模型：

- 如果你用 **DeepSeek 账户**登录，请选择 `deepseek-account` 分组下的模型；
- 如果你用 **API Key** 登录，请选择 `deepseek` 分组下的模型。

选好后，底部状态栏左侧会立刻显示你刚刚选中的模型名称。如果后续想临时换模型只影响当前对话，可在模型列表里按 `Ctrl+D` 选择 `仅当前会话`（`This session only`）。

## 第一步：先让助手读懂项目

先不要急着改代码，让助手只读检查一次项目，熟悉它的输出方式。在输入框中发送：

```text
概括这个项目的目录结构、入口文件和运行测试的方法，先不要修改任何文件。
```

发送后你会看到几个关键细节：

- **紧凑的执行过程**：思考内容和文件读取工具调用默认以紧凑行显示，完成后会自动折叠成一行摘要（中文界面显示 `处理耗时 …`，英文界面显示 `Worked for …`），最终回复保持完全展开。
- **随时展开查看细节**：按 `Ctrl+O` 可以展开或收起已完成回合的思考与工具详情；也可以直接用鼠标点击折叠箭头查看某一步读取了什么文件。
- **底部状态栏实时更新**：完成后，底部第二行会更新上下文占用比例（`Ctx`）、缓存命中率（`Cache`）、首字延迟（`TTFT`）和输出速度（`tok/s`）。注意：为了保持宽度和位置稳定，底部状态栏的指标标签在中文界面下也会保持英文简写。

## 第二步：完成第一次安全改动并用 `/diff` 验收

接下来让助手做一次低风险、好验证的小改动——例如为 `README.md` 补充一处说明，或为一个函数补一条注释或单元测试。发送你的具体要求，例如：

```text
帮我检查 src/utils 里的日期格式化函数，补一个空字符串边界情况的单元测试，并运行测试验证。
```

在助手动手改文件和跑命令时，你会接触到日常最核心的两个安全机制：

1. **权限控制（`/permission`）**：
- 默认的 `工作区可写`（`Workspace write`）模式允许助手读写当前项目目录里的文件；
- 一旦操作超出当前工作区、涉及敏感命令或需要确认，底部会弹出带有**警告色边框**的审批卡片，清楚列出要执行的内容，你可以选择允许、拒绝，或记住这条规则。
- 如果你只想让它纯阅读分析、绝对不能改文件，随时运行 `/permission` 切换到 `只读`（`Read only`）；如果你想减少手动点确认又多一层把关，可以切换为内置的 `自动审查`（`Auto review`），详见[权限与安全](../permissions.md)。
2. **审查改动（`/diff`）**：
- 回合完成后，对话记录里会出现本轮改动文件的汇总（`Changed`），直接点击文件名或输入 `/diff` 就能打开交互式 Diff 阅读器。
- 在宽终端下，`/diff` 会左侧列出改动文件、右侧展示增删对比；按 `V` 可在“对比视图”和“当前完整文件”间切换，按 `Esc` 返回对话。
- 如果对某几行改动不满意，可以直接在 Diff 里选中文字后按 `Alt+Y`（或按 `Q`）把代码位置引用回输入框，接着让助手调整。

## 界面操作小贴士

第一次使用时，记住这 4 个习惯就够用了：

- **换行与发送**：`Enter` 发送消息，`Shift+Enter` 或 `Ctrl+J` 换行（几乎所有终端都支持 `Ctrl+J`）。
- **复制文字**：如果鼠标直接拖拽无法选中文字（因为默认开启了界面滚轮和点击支持），可以按住 `Shift`（macOS 部分终端按 `Option`）再拖选，或者在 `/settings` 的 `终端 → 鼠标交互` 中调整。
- **中断与退出**：模型运行中按 `Esc` 或 `Ctrl+C` 可立刻中止当前生成；空闲时连按两次 `Ctrl+C` 退出，退出时会打印一行 `omdsh --resume <会话ID>`，方便下次原样续接。
- **随时查帮助**：忘记命令时输入 `/` 触发自动补全，或运行 `/help` 搜索命令、`/help full` 查看全部快捷键。
