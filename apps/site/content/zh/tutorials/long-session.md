# 恢复并管理长会话

读完本教程，你可以在退出后恢复会话、回退到更早的回合、压缩旧历史，并导出 Transcript。

### 退出后恢复

第一次 `Ctrl+C` 会清空输入或中断，第二次则退出。当活动会话可以持久化时，omdsh 会输出一条以后可以直接粘贴的命令：

```sh
omdsh --resume <session-id>
```

在 TUI 内运行 `/resume` 会打开可搜索的会话选择器，其中包含最近一条用户消息的预览、更新时间、Event 数量和完成状态。如果已经知道会话 ID，可以使用 `/resume <session-id>` 跳过选择器。会话日志、Session Library 与本地数据文件的说明见[会话与历史](../sessions.md)。

### 保留历史并探索分支

Agent 空闲且 Composer 为空时，连续按两次 `Esc` 打开 Session Tree。使用 `↑`/`↓` 浏览回合与分支，`←`/`→` 折叠，输入文字搜索，并预览选中内容。在 Turn 上按 Enter，会从该消息之前创建新分支，把原始文本、图片与文件引用恢复到 Composer，不自动发送。在分支节点上按 Enter，或按 `Alt+Enter`，会恢复该分支的最新状态。原有分支仍可打开；这些操作不会回滚工作区文件。

两个邻近命令覆盖其他会话场景：

- `/continue` 继续可恢复的模型失败，不重复提示；`/retry` 则把最近一条用户 Prompt 连同图片和文件作为新回合重发。
- `/new` 从空白状态开始新会话，而不是从当前会话分支。

### 压缩与导出

先运行 `/context` 查看上下文占用和会话概览。如果对话越来越长，可以检查分类构成，再决定是否压缩。界面会区分实测用量与估算值，详细说明见[可观测性](../observability.md)。

Agent 空闲时运行 `/compact`，可以用摘要替换一段有价值的旧历史。压缩状态会一直保持到持久化检查点完成。压缩期间可以继续输入，按 Enter 将下一条消息排队，等压缩结束后再接收执行。Ctrl+C 中断压缩。如果摘要生成失败，或在写入检查点之前取消，模型仍可使用原始历史。如果历史不足，命令会说明当前没有可压缩内容。

完成提示后可按 `Ctrl+O` 展开已保存的摘要，再按一次回到实时底部。恢复会话后仍可阅读这些摘要；展开不会改写终端原生历史。

运行 `/export` 选择 Markdown、HTML 或会话归档，再选择保存路径。结果页提供适用的复制、预览和打开操作。直接导出 Markdown 时可指定格式和路径。

```text
/export markdown docs/session-review.md
```

### 了解旧会话的兼容边界

omdsh v0.12.0 及更高版本不再写入私有的 `omdsh/tools-selected` 事件，因此新建会话可以由未经扩展的 DSH 持久化读取器加载。最初使用 v0.5.0 至 v0.11.0 创建的会话仍可能包含该事件：当前 omdsh 可以识别并恢复这些会话，但未经扩展的 DSH 读取器会拒绝这类日志。会话文件可能经过压缩并带有完整性校验，请勿手工修改；请通过 omdsh 打开这些旧会话。日志同时需要 Harness 格式迁移时，交互式恢复会先确认，再在原文件旁生成带版本名的后继文件。激活与迁移规则见[会话兼容说明](../sessions.md)。
