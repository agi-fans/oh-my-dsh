# 会话与恢复

omdsh 把每段对话保存为持久化的本地日志，支持随时恢复、开分支试错、按回合恢复文件、压缩上下文和导出归档。想看一步步实操请先读[管理长会话与安全回退](tutorials/long-session.md)，本页提供完整的规则与数据位置参考。

## 常用会话操作速查对比

| 操作 | 做了什么 | 什么时候用 |
|---|---|---|
| `/resume` / `omdsh --resume <id>` | 恢复历史会话（支持全文搜索） | 接着之前的对话继续工作 |
| `/continue` / 空输入框按 `Alt+R` | 从中断处续跑模型回复，不重发原消息 | 遇到网络抖动、限流或服务端瞬时错误 |
| `/retry` | 带着原来的文字、图片和文件附件重跑上一轮 | 对上一轮方向不满意，或换了模型/推理强度想重来 |
| `/compact [说明]` | 把早期长对话压缩为精炼摘要 | `Ctx` 占比偏高，想留在同一会话里继续 |
| `/new` | 新建完全干净的会话 | 切到无关的新任务（发消息前可换 Agent 预设） |
| `/clear` | 清空当前上下文并留一条分界线 | 重头再来，同时保留上方终端滚动记录 |

> **原生滚动历史永不被清空**：执行 `/clear`、切换会话、`/resume` 或分叉会话时，终端上方原有的滚动历史（包括启动 `omdsh` 前你自己的 shell 输出）始终完整保留，并用一条带标签的分界线隔开新旧内容。普通启动、换预设、开关工具列表、进出子智能体视图不显示分界线；`/new` 仅在原对话已有实质内容时才画分界线。

## 一、恢复与整理会话（Session Library）

运行 `/resume` 打开当前工作目录的会话库：

- **目录隔离**：默认列表、最近会话、补全和内容搜索只包含**记录目录与当前工作目录一致**的会话（不混入父目录或子目录）。要打开其他目录的会话，使用 `/resume <会话ID>` 或命令行 `omdsh --resume <会话ID>`。
- **全文搜索**：运行 `/resume <关键词>`，或在会话库中按 `Alt+S` 全文搜索历史内容（基于首次搜索时构建的 SQLite FTS5 索引，即使早期内容已被压缩或折叠也能搜到）；按 `Alt+L` 返回当前目录全部会话。
- **整理快捷键**：
- `Alt+P`：置顶 / 取消置顶；
- `Alt+R`：手动重命名（手动命名后不会被自动标题覆盖）；
- `Alt+A`：归档 / 取消归档（会同步更新工作区注册表，与定时提醒及 Git worktree 生命周期保持一致；在“归档时保留 worktree”默认开启时会保留该 worktree）；
- `Alt+V`：在默认列表和归档列表之间切换。

## 二、会话树与分支探索（Session Tree）

在空输入框下**连按两次 `Esc`** 打开当前会话的分支树（包含同一工作区内相关分支；子智能体通过输入框上方的子智能体列表进入，不混入主树）：

- **导航与搜索**：`↑`/`↓`/`Tab` 移动，`←`/`→` 折叠或展开子树，直接打字可筛选节点（自动保留匹配节点的祖先路径）；`Ctrl+↑`/`Ctrl+↓` 滚动右侧或下方的预览。
- **进入分支**：
- 在某个**历史回合**上按 `Enter`（`edit from here`）：从该消息之前分出新分支，并把原文字、图片和文件引用填回输入框供你修改（不会自动发送）；
- 在**分支节点**上按 `Enter` 或按 `Alt+Enter`（`continue branch`）：直接切换到该分支的最新状态继续对话。
- **节点标记**：`Alt+L` 给回合或分支打标签（最多 120 字，仅本地保存、不进入模型上下文），`Alt+U` 清除，`Alt+B` 切换只看已标记节点。

## 三、按回合恢复文件（文件恢复快照）

切换会话分支只改变对话历史，不会动磁盘文件。如需同时回退某一回合修改的文件：

1. **提前开启**：在 `/settings` → **`插件` → `工具` → `文件恢复快照`** 打开（默认关闭，开启后从下一回合起生效）。
2. **三步恢复**：双按 `Esc` 打开会话树 → 选中目标回合按 **`Alt+R`** → 勾选要恢复的文件、逐个对比“回合前 / 回合后”内容并确认。按 `Alt+H` 可查看历史恢复报告。
3. **安全保护与边界**：
- 恢复前会重新比对文件与回合结束时的状态——**回合后你手动改过或其他进程改过的文件会标记为冲突并保留**，不会盲目覆盖；被替换的文件也会保留为 `.omdsh-recovery-<id>.backup` 备份；
- 恢复不改动对话记录、当前分支和 Git 暂存区，并在下一步提醒模型重新读取相关文件；
- `只读` 权限下禁止执行恢复；回合中途切换工作目录、文件超过 128 MiB、单次快照超过 1 GiB 或文件数超过 10,000 时，该回合不会生成不完整快照；
- 快照与报告保存在本机 `omdsh/file-recovery/`（不包含在 `/export archive` 导出的压缩包中），不会自动清理，可随时手动删除释放空间。

## 四、模型失败后续跑（`/continue` 与 `/retry`）

- 当模型遇到瞬时故障（限流、服务端错误、超时、连接中断、空响应）且内置自动重试仍未成功时，可用 `/continue`（或空输入框按 `Alt+R`）接着生成，不会重复发送你的原提问；
- 正常结束、手动打断、认证/配置报错和工具调用失败不属于可续跑的瞬时故障；如果只是想重新回答一次，请用 `/retry`；
- 两者都要求当前主会话空闲且没有待发消息或未处理的审批弹窗。

## 五、运行中的待处理消息（排队、插话与队列恢复）

| 方式 | 快捷键 | 投递时机 | 适用场景 |
|---|---|---|---|
| **排队（下一回合）** | `Alt+Enter`（Windows / WSL 亦可用 `Ctrl+Q`），或默认设置下按 `Enter` | 当前回合完全结束后作为下一回合发送 | 顺着当前方向继续安排下一步任务 |
| **插话（下一步）** | `Alt+S` | 在模型下一次推理步骤前注入，**不打断正在跑的工具调用** | 及时纠正方向、补充约束 |

可在 `/settings` → **`终端` → `输入` → `繁忙时的发送行为`** 修改运行中按 `Enter` 的默认行为；`Cmd+Enter` / `Ctrl+Enter` 始终执行另一种行为。两种方式都完整保留文字、图片和文件附件。

### 管理队列（`Alt+↑` 与 `/queue`）

- 空输入框按 **`Alt+↑`**：把最近一条排队消息拉回输入框修改（若输入框已有草稿，会暂存并在取消时恢复）。
- 运行 **`/queue`** 或按 **`Alt+Q`**：打开实时队列面板，按状态分组显示 `插话 · 下一步`、`排队 · 下一回合` 和 `发送中 · 尚未接收`：
- `Enter` 编辑内容（保留附件）；`Alt+S` 将选中的已接收排队消息升级为插话；`Alt+D` 撤回；`Alt+↑` / `Alt+↓` 在同组内调序；`Esc` 退出并保留草稿。
- **中断与重启说明**：按 `Esc` 或空输入框按 `Ctrl+C` 中断当前回合时，已进入队列的消息仍会保留在 `/queue` 中供你决定去留。但**正常退出或切换会话后，尚未发出的队列不会自动重跑**——重启后，本地留存的待发送输入会在 `/queue` 中标为 **`已恢复 · 确认后发送`**，选中按 `Alt+R` 确认发送，或拉回输入框修改后再发，避免误重复执行。

## 六、未发送草稿与旧会话日志

- **草稿自动保存**：输入时短暂停顿、切换会话或退出时会自动保存当前草稿、光标位置、折叠粘贴块原文和附件（主会话与各子智能体各自独立保存）；发送或清空后清除。草稿不包含在会话导出中。
- **旧版日志迁移**：早期版本的会话日志会在列表里标为 `migration required`，选中时经你确认后生成新版本文件（原文件保留不动）。使用 v0.5.0–v0.11.0 创建的旧会话可能含早期私有事件，omdsh 仍可正常打开；v0.12.0 及之后创建的会话完全兼容标准 DSH 日志读取器。

## 七、可移植归档（`/export archive`）

- `/export` 支持导出 **Markdown**、**HTML** 和 **Archive（`.zip`）**；
- `/export archive [路径]` 会打包完整会话 JSONL、关联子智能体记录、校验后的原始图片与文件附件以及 `manifest.json`（未压缩上限 64 MiB，目标已存在时拒绝覆盖）；
- 归档内容**不做脱敏**，且仅用于备份与查阅，不支持自动导回 omdsh；文件恢复快照不包含在归档内。

## 八、本地数据文件清单

全部数据默认保存在 `$OMDSH_HOME`（未设置时依次回退到 `$DSH_HOME`、`~/.dsh`）：

| 路径 | 存放内容 |
|---|---|
| `sessions/` | 持久化会话日志（JSONL，可能压缩并带校验，请勿手工修改）。 |
| `sessions-query.sqlite` | 会话全文搜索索引（删除后下次搜索自动重建）。 |
| `storages/` | 持久键值数据、工作区注册表与定时提醒记录。 |
| `profiles/omdsh/` | 用户插件安装目录与持久化配置补丁 `cordis.patch.yml`。 |
| `omdsh/drafts/` | 按会话保存的未发送草稿及图片字节。 |
| `omdsh/history.jsonl` | `Ctrl+R` 使用的输入历史。 |
| `omdsh/keybindings.json` | 自定义快捷键覆盖配置。 |
| `omdsh/model-favorites.json` | 收藏模型轮换列表（`/model favorite`）。 |
| `omdsh/session-library.json` | 会话置顶、归档状态与本地会话树标记。 |
| `omdsh/recent-sessions.json` | 会话库标签缓存（删除后自动重建）。 |
| `omdsh/file-recovery/` | 按回合保存的文件恢复快照、校验清单与恢复报告。 |
| `omdsh/approval-rules/` | 记住的审批允许/拒绝规则（最多 500 条）。 |
| `omdsh/btw/` | `/btw` 旁路提问记录。 |
| `omdsh/logs/omdsh.log` | 交互模式下插件的诊断日志输出（删除即可重置）。 |
