# 状态与诊断

omdsh 界面里的所有统计数字（上下文占用、缓存命中率、耗时、改动文件、调用轨迹）都直接读取自运行时的持久日志与实时计量，而不是界面自己估算的假计数器。

## 按问题找工具

| 你现在想知道什么 | 用哪个工具 |
|---|---|
| 上下文是不是快满了？主要是哪部分占的？ | 瞄一眼底部状态栏 `Ctx`，或运行 **`/context`** |
| 刚才这一轮为什么这么慢？哪个工具报了错？ | 运行 **`/trajectory`**，按 **`s`** 按耗时排序，或按 **`e`** 只看报错 |
| 助手刚才到底改了哪些文件的哪几行？ | 点回合 **`Changed`** 摘要，或运行 **`/diff`** / **`/diff turn`** |
| 某个 MCP 服务器连上了没？最近调用有没有失败？ | 运行 **`/mcp`** 查看实时连接状态与最近 10 次调用 |

## 一、底部状态栏

状态栏固定在输入框正下方，采用**固定左右布局**（数字永远在同一个位置，不会左右跳动）：

- **第一行**：左侧显示当前身份（模型、推理强度、可选会话名），右侧显示工作位置（目录路径与 Git 分支/脏状态）。
- **第二行**（会话指标）：左侧回答“占了多少、花了多久”（`Ctx` 上下文占用、`Cache` 缓存命中率），右侧回答“跑了多快、做了多少”（`TTFT` 首字延迟、`tok/s` 输出速度 / Token 数）。
- **第三行**（仅 `verbose` 密度且屏幕足够宽时出现）：左侧显示会话累计耗时（LLM/工具时长），右侧显示累计轮次与步数。
- **宽度不足时**：严格按 **轮次/步数 → 耗时 → 延迟/Token/缓存** 的优先级从低到高隐藏，不会乱序出现。
- 运行 `/settings` → **`终端` → `状态栏`** 可以实时调整密度与单项显示——改动会**直接在设置面板正下方的真实状态栏上实时生效并下划线高亮当前项**。

## 二、`/context`：上下文占用与构成估算

运行 `/context` 会打开紧凑的实时总览卡片：

- 左侧 **5×8 占用点阵**与右侧 5 行核心数据一一对齐（已用 / 总容量、剩余预算、本轮次数与累计输入输出 Token、当前预设与权限模式）；
- 占用超过 **75%** 呈警告色，超过 **90%** 呈错误色；
- 下方列出三大来源的估算占比：**System prompt**（系统提示）、**Tool schemas**（工具定义——如果你连了很多 MCP 服务器，这里会明显变大）、**Conversation messages**（对话消息）；
- 底部按钮支持打开完整 **`详情`（`Details`）**、一键 **`复制会话 ID`** 或直接发起 **`压缩`（`Compact`）**。

## 三、`/trajectory`：执行轨迹与耗时排查

当一轮操作经过了十几次工具调用、甚至派生了子智能体时，`/trajectory` 就是最清晰的“调用账本”：

- 逐回合、逐步骤展示每条工具调用、命名子智能体（显示名称与层级路径）、记录的状态、耗时与 Token 用量（上下文条目与嵌套子调用默认折叠，按 `Space` 展开）；
- 选中任意记录按 `Enter` 打开右侧详情，按 `←` / `→` 切换 **`Overview`**、解码后的 **`Input`**、**`Result`**、原始事件 **`Raw`** 与 **`Schema`**；
- **三个最实用的排查快捷键**：
- **`s`**：按耗时从长到短排序，一眼抓出拖慢全轮的慢命令或大查询；
- **`e`**：一键只筛选失败或报错的调用；
- **`/`**：搜索所有记录（包括已折叠的内容），`y` 复制当前分区内容，`f` 放大详情。
- 耗时条标有 `Σ` 时表示记录耗时的累计和（非真实挂钟时间），父调用已含其 `PTC` 子调用耗时，不会重复计算。

## 四、`/diff` 与回合改动摘要

- 对话记录中每个改过文件的回合都会附上可点击的 **`Changed`** 摘要，点标题看整轮对比，点单个文件名直接跳到该文件（可在 `/settings` → `常规` → `文件变更摘要` 关闭显示，但 `/diff turn` 仍随时可用）；
- 运行 `/diff` 查看当前 Git 改动，运行 `/diff turn [回合号]` 查看指定回合快照；
- 终端宽度 ≥ 100 列时自动左右双栏，支持 `V` 切换对比/完整文件、`[`/`]` 跳变更块、`/` 搜索、`G` 跳行号，以及**选中代码后按 `Alt+Y` 或 `Q` 直接引用回输入框**。

## 五、`/mcp` 与原生终端状态集成

- **`/mcp`**：实时展示每个托管和静态 MCP 服务器的连接状态（`connected`、`connecting`、`waiting-credentials`、`reconnecting`、`disabled`、`closed`、`failed`）、可用工具数和本会话最近 10 次调用。
- **终端窗口与 Herdr 面板集成**：当你在支持原生状态上报的终端（如 Herdr，或支持 OSC 9;4 进度条的终端）中运行 omdsh 时，标签页/侧栏会自动同步当前会话是“运行中”“等待你审批/输入”还是“已完成/报错”，并同步当前工作目录方便新开分屏继承。可在 `/settings` → **`终端` → `终端标题` / `终端状态`** 开关。
