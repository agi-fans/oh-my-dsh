# 可观测性

omdsh 展示的一切都读自 Harness 的 projection 和持久会话日志；下面的视图只是这些数据的呈现，而不是 TUI 自造的计数器。

## 会话账本：`/trajectory`

`/trajectory` 打开按回合和模型步骤组织的交互账本。工具行显示可读的命令或文件摘要与已记录状态，上下文记录和嵌套调用默认折叠。耗时总览帮助定位耗时较多的步骤，列表在你离开实时底部之前跟随新记录。

- 点击记录或按 `Enter` 查看详情，可用分区包括 Overview、解码后的 Input、Result、Raw 和 Schema。工具结果显示为纯文本，结构化输入和原始 JSON 保留代码格式。长行折行时使用独立行号列。
- `Tab` 切换列表与详情焦点，方向键和翻页键操作当前面板，滚轮滚动指针所在面板。`f` 放大详情，`y` 复制当前分区，`Esc` 逐层返回对话。
- `Space` 展开上下文或嵌套调用，`t` 折叠回合，`c` 折叠调用。`e` 筛选问题，`s` 按耗时从高到低查看调用。
- `/` 搜索全部记录，包括折叠内容。`n`/`N` 跳转匹配，输入搜索词时使用 `Ctrl+N`/`Ctrl+P`。Enter 定位匹配并打开对应内容。

耗时和 Token 数量来自记录的事件，缺少耗时的列留空。账本需要交互式终端，完整按键见[键盘与快捷键](keyboard.md)。

## 上下文与会话概览

`/context` 打开实时面板，展示预计占用、剩余容量、分类估算和会话活动。宽终端采用紧凑占用网格，窄终端采用横条。分类采用启发式估算，与校准后的总占用独立计数；缺少的测量值会标为暂无数据。

按 Tab 和 Enter 或点击操作按钮，可打开详情、复制会话 ID，或调用已挂载的 `/compact` 命令。详情包含模型、推理强度、工作流、权限、队列数量、累计提供商用量和最近的 token 采样。面板支持滚轮阅读、搜索和文字选择。选中文字时暂停刷新，Esc 恢复对话位置和草稿。非交互模式输出完整文本报告。

底部状态栏在 minimal 和 standard 密度下显示上下文占用百分比，verbose 增加已用量与窗口容量。占用升高时使用警告或错误颜色，配置方式见[调整工作环境](tutorials/environment.md)。

## 工作区差异：`/diff`

`/diff` 打开文件浏览器，审阅当前工作区相对 HEAD 的改动，包括暂存、未暂存和未跟踪文件。`/diff <path>` 打开单个文件，`/diff turn [number]` 读取保留的回合比较。历史比较缺失时明确标记不可用；按 `V` 才会切换到当前内容。普通文本模式保留摘要与 patch 输出。这些命令只读取 Git 状态，不会暂存或提交。

## 每轮改动的文件

每个完成的回合结束时会附一条记录，列出该回合改动的文件、该回合的增删总行数，以及每个路径各自的新增与删除行数。改动归属于产生它的那一回合，因此长会话里能看出哪次改动来自哪次请求，而不是只有一个累计总数。文件列表超过八个会折叠，`Ctrl+O` 展开；没有改动的回合会明确说明，binary 或超大的文件只做标记而不给行数。由于这条记录来自该回合自己的快照，之后再打开的会话会显示该回合，但没有它的文件列表。

`/diff` 与这条记录回答的是不同问题：`/diff` 报告当前工作区的状态，而每轮记录报告某一个回合改了什么。

## 工具与集成：`/tools` 与 `/mcp`

`/tools` 打开可搜索的目录并预览说明，Enter 阅读完整说明，Esc 返回列表。`/mcp` 按服务器提供工具数量与最近调用入口，同时提供可搜索的工具目录和排版后的诊断页面。这些视图展示已暴露的工具和已记录的结果，当前发布的 Harness API 尚未提供实时连接与认证状态。目录变化后可重新打开 `/tools` 或刷新 `/mcp`。超过上下文预算的工具结果会溢写到私有文件，转录中保留有界预览，原始内容仍可用 `read` 或 `grep` 读取。

## Herdr 面板集成

在 Herdr 面板中运行时，omdsh 通过本地 socket 注册为一等 agent（在回合与压缩期间报告 `working`，以及 `idle` 和指明待处理审批或问题的 `blocked`），上报可恢复的会话 id，并在退出时释放面板；嵌套启动的 omdsh 子进程保持静止，不会覆盖父面板状态。在基于 `herdr-core` 的终端（包括 Herdr App）中，omdsh 通过 OSC 7501 实时上报 `idle`、`working`、`blocked`、`done`、`error` 生命周期状态与会话标题，并在挂起、调用外部编辑器或退出时清除状态。
