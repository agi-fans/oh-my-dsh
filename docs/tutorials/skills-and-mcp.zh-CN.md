# 使用 Skills 与 MCP 扩展项目

[English](skills-and-mcp.md) | 简体中文

[教程](../tutorials.zh-CN.md) · Previous: [调整工作环境](environment.zh-CN.md) · Next: [安装示例插件](install-plugin.zh-CN.md)

项目 Skills 位于 `.dsh/skills` 或 `.agents/skills`。增加可由用户调用的 Skill 后，输入 `/skill:` 即可像浏览普通命令一样查看并筛选。MCP Server 配置位于 `.dsh/mcp.json`；`/mcp` 用于查看已连接的 Server，`/tools` 则会把 MCP Tools 与原生 Harness Tools 一起展示。

完整的搜索优先级、`SKILL.md` 结构、stdio 与 HTTP 示例、环境变量展开、覆盖规则和当前协议限制，请参阅 [Skills 与 MCP](../skills-and-mcp.zh-CN.md)。Skills 与 MCP 不是 DSH bundle。要编写并安装命令、工具、提供方或 Auth bundle，请继续 [编写插件](write-a-plugin.zh-CN.md) 和 [用户插件](../plugins.zh-CN.md)。
