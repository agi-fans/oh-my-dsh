# Extend a project with Skills and MCP

[English](skills-and-mcp.md) | [简体中文](skills-and-mcp.zh-CN.md)

[Tutorials](../tutorials.md) · Previous: [Tune the working environment](environment.md) · Next: [Install the example plugin](install-plugin.md)

Project Skills live under `.dsh/skills` or `.agents/skills`. After adding a human-invocable Skill, type `/skill:` to browse and filter it alongside other commands. MCP servers are configured in `.dsh/mcp.json`; `/mcp` shows connected servers and `/tools` shows their tools beside native Harness tools.

Follow [Skills and MCP](../skills-and-mcp.md) for complete search priority, `SKILL.md` structure, stdio and HTTP examples, environment expansion, override rules, and current protocol limitations. Skills and MCP are not DSH bundles. To write and install a command, tool, provider, or auth bundle, continue with [Write a plugin](write-a-plugin.md) and [User plugins](../plugins.md).
